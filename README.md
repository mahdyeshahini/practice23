## 🖥️ عنوان آزمایش:  کنترل نمایشگر 7 سگمنت با استفاده از میکروکنترلر آردوینو

## 💡 شرح آزمایش: 
این آزمایش به منظور آشنایی با نحوه استفاده از میکروکنترلر آردوینو برای کنترل نمایشگر 7 سگمنت طراحی شده است. نمایشگرهای 7 سگمنت معمولاً برای نمایش اعداد و گاهی حروف استفاده می‌شوند و در این آزمایش قصد داریم که از آنها برای نمایش اعداد 0 تا 9 استفاده کنیم. با استفاده از پین‌های دیجیتال آردوینو، وضعیت هر یک از پایه‌های نمایشگر تعیین می‌شود تا در نهایت یک عدد خاص روی نمایشگر نمایش داده شود.

در این کد، ابتدا یک آرایه دو بعدی به نام sequence تعریف شده که در آن برای هر عدد از 0 تا 9، وضعیت هر پین مرتبط با نمایشگر مشخص می‌شود. هر ردیف این آرایه معادل یک عدد است و ستون‌ها وضعیت هر پین را از 1 (روشن) و 0 (خاموش) نشان می‌دهند. سپس با استفاده از تابع digitalWrite، وضعیت هر پین تنظیم می‌شود تا نمایشگر وضعیت درستی را برای اعداد مختلف نشان دهد.

## 🎯 هدف آزمایش:
 هدف این آزمایش، آشنایی با اصول پایه‌ای کنترل نمایشگر 7 سگمنت با استفاده از آردوینو است. هدف از این آزمایش این است که دانشجویان و علاقه‌مندان به الکترونیک و برنامه‌نویسی آردوینو، نحوه کار با نمایشگرهای 7 سگمنت و روش‌های مختلف برنامه‌نویسی برای کنترل آن‌ها را فرا بگیرند. این آزمایش همچنین به درک بهتر نحوه ارتباط بین سخت‌افزار و نرم‌افزار و نحوه استفاده از آرایه‌ها در کد برنامه‌نویسی کمک می‌کند
